# 解密工具使用说明

## 环境依赖

- Python 3（设备自带或 MT 终端内置）
- Java（用于 unluac 反编译）
- 目录 `unluac-classes/`（已附带）

## 目录说明

```
解密工具/
├── 1_文件解密.py        # 第一层：文件层解密
├── 2_转标准luac.py      # 第二层 + 转标准 luac（包装上级 解密脚本.py）
├── 3_转义解码.py        # unluac 输出八进制转义 → 中文
├── 批量解密.sh          # 一键流水线
├── unluac-classes/      # unluac 反编译工具（Java）
└── 使用说明.md
```

## 快捷用法（推荐）

```sh
cd /storage/emulated/0/MT2/mcp
sh 解密工具/批量解密.sh
```

默认：

- 输入：`原始加密脚本/`（从 script.lr 解包出的加密文件）
- 输出：`解密产物/`
  - `1_解密后LuaBinary/` 第一层解密结果
  - `2_标准luac/` 标准 Lua 5.3 luac
  - `3_反编译源码/` unluac 反编译结果（`*.lua` 原始 + `*.decoded.lua` 中文可读）

也可以指定目录：

```sh
sh 解密工具/批量解密.sh <输入目录> <输出根目录>
```

## 单步用法

```sh
# 1) 只看某个文件的结构（不解密写盘）
python3 解密脚本.py 原始加密脚本/脚本/抖音私信助手.lua --info

# 2) 单个文件解密为标准 luac
python3 解密脚本.py 原始加密脚本/脚本/page.lua /tmp/page.luac

# 3) 批量转标准 luac
python3 解密工具/2_转标准luac.py 原始加密脚本/脚本 /tmp/out_luac

# 4) 反编译（注意：Java 不支持中文路径，先把 luac 复制成 ASCII 文件名）
cp /tmp/out_luac/page.luac /tmp/p.luac
java -cp 解密工具/unluac-classes unluac.Main /tmp/p.luac > /tmp/p.lua

# 5) 转义解码（把 \229\136\135 还原为“切”）
python3 解密工具/3_转义解码.py /tmp/p.lua
```

## 注意事项

1. **Java 不支持中文路径**：`批量解密.sh` 已自动先把 classpath 与输入复制到 `/tmp` 下的
   ASCII 路径再调用；手工调用 unluac 时请同样处理。
2. 每个加密文件的 30 字节密钥不同，工具会自动从各文件头读取，请勿手工混用。
3. `插件/File.lua`（ver=1）暂不支持，会被提示跳过。
4. 反编译输出里的 `????????` 是脚本作者对局部变量名的混淆（原始 debug 名即为 `?`），不影响逻辑阅读。
